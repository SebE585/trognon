# Non-iOS systems on 32-bit A5/A6 devices

Research date: 2026-10-13. Web sources; nothing reproduced on hardware.

## Bottom line

Linux boots on exactly one A5 device, very recently: **Project Cascadia**
(iPad mini 1, S5L8942). No port exists for iPhone 4S (S5L8940), iPhone 5/5c
(S5L8950), iPad 2/3/4 or iPod touch 5. Cascadia is the base the 4S track
should start from.

## Project Cascadia (rzxvx)

https://github.com/rzxvx/Project-Cascadia · https://ipadlinux.org/

- Target: iPad mini 1 Wi-Fi (iPad2,5, S5L8942X) only.
- Mainline Linux 6.12 + one Apple patch + custom AIC driver; Alpine 3.24, XFCE.
- Works: both cores, multitouch, Wi-Fi (open networks tested), SSH. Not
  working: USB accessories. GPU: Mesa milestones listed in the repo, contrary
  to the ipadlinux.org summary — check.
- Started May 2026; milestones 2026-09-29, 2026-10-02, 2026-10-04.
- Boot: primepwn → patched iBSS → "autogo" iBEC → staging loader → zImage at
  0x80008000. Pwned DFU via a Pico running checkm8, or kDFU from jailbroken
  iOS. Runs from host/RAM, nothing on NAND yet.
- Roadmap: A6/A6X (iPad 4). No mention of iPhone 4S or iPad 2.

Earlier, same device: iBSSloader (teutekeune), kernel builds, hardware boot
"in progress"; notes pongoOS is AArch64-only, so unusable on A5.
https://github.com/teutekeune/iBSSloader

## checkm8 on A5/A6

- **A6/A6X (8950/8955):** native in ipwndfu over plain USB; less reliable
  under Linux hosts (Legacy iOS Kit). Tools: ipwnder32, ipwnder_lite, gaster,
  primepwn, kurouta dori. https://github.com/axi0mX/ipwndfu
- **A5/A5X (8940/8942/8945):** needs a USB-host microcontroller,
  **checkm8-a5** (a1exdandy, nyan_satan, 2020-06-18).
  - Arduino (ATmega, not CH340 clones) + MAX3421E USB Host Shield,
    USB_Host_Shield_2.0 @ cd87628 + patch. Default demotes the device (SWD on,
    development KBAG).
  - Recommended today: **RP2040 Pico** with a per-SoC UF2 and a micro-USB OTG
    Y-cable (~June 2024). RP2350 (Pico 2) does not work.
  - SoC map: 8940 = iPhone 4S, iPad 2 (except iPad2,4); 8942 = iPad2,4, iPad
    mini 1, iPod touch 5; 8945 = iPad 3.
  - https://github.com/LukeZGD/Legacy-iOS-Kit/wiki/checkm8-a5 (edited
    2026-06-28) · https://github.com/synackuk/checkm8-a5
- checkm8_bootkit (NyanSatan): boots custom bootloaders on 32-bit.
  https://github.com/NyanSatan/checkm8_bootkit

## History and tools

- OpeniBoot / iDroid (planetbeing): Linux 2.6 in 2008, only S5L8900 (2G, 3G,
  iPod touch 1) in the final release; A4 partial; dead 2012. Never A5/A6.
- kloader / ios-kexec-utils (winocm, ~2014-03-31), needs tfp0.
- CoolBooter (2016, v1.6 2020-10): dual-boot iOS 5.0–10.3.3 on 32-bit.
- iBoot32Patcher (iH8sn0w): patches 32-bit iBoot signature checks/boot-args.
- Legacy iOS Kit (LukeZGD): OTA downgrades to 8.4.1/6.1.3, SSH ramdisks,
  kDFU on A5/A6. https://github.com/LukeZGD/Legacy-iOS-Kit
- n1ghtshade (synackuk): A6/A6X checkm8 tool.

## Not verified

- Any use of kloader/CoolBooter to load a non-iOS kernel.
- "a6meowing" (listed by Legacy iOS Kit).
- Exact dates of iBSSloader and the checkm8-a5 forks.
- Absence of any 4S/A6 Linux attempt (none found ≠ none exists).
- Some Apple Wiki pages returned 403; details from search summaries.

## Implication for Trognon

The iPhone 4S shares the A5 family with the iPad mini 1. Porting Cascadia from
S5L8942 to S5L8940 (iPhone 4S, iPad 2) is a concrete, scoped first job — and
the Pico checkm8-a5 is already the "dongle" building block.
